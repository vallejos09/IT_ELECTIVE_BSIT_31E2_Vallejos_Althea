## 📌 Project Description
This project demonstrates a simple login system built with ASP.NET Core MVC.  
It covers:
- Model Binding
- Data Annotation validation
- Use of ModelState.IsValid
- Login authentication with hard-coded credentials
- Redirect to a Welcome page upon successful login
- Responsive split-screen UI with frosted glass effect
